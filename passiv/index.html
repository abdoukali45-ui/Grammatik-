❖ Vorgangspassiv (المبني للمجهول): نركّز على الحدث أو المفعول به، وليس على الفاعل. نبنيه بالفعل werden مع Partizip II.

Das Vorgangspassiv

Die Formel

Subjekt + werden (in der Zeitform) + … + Partizip II

werden

PräsensPräteritum

Aktiv → Passiv

  1. مفعول Akkusativ في Aktiv يصبح فاعلًا (Nominativ) في Passiv.
  2. الفاعل في Aktiv يصبح Agens: von + Dativ للأشخاص، وdurch + Akkusativ للأشياء والوسائل.
  3. نصرّف werden في الزمن نفسه وبما يناسب الفاعل الجديد.
  4. نضع Partizip II في آخر الجملة.

تنبيه: مفعول Dativ لا يصبح فاعلًا، بل يبقى Dativ في Passiv.

Präsens

المضارع

Formel

werden (Präsens) + Partizip II

Aktiv: Die Frau kauft das Haus.
Passiv: Das Haus wird von der Frau gekauft.
Aktiv: Das Fernsehen informiert den Zuschauer.
Passiv: Der Zuschauer wird durch das Fernsehen informiert.

Präteritum

الماضي البسيط

Formel

werden (Präteritum) + Partizip II

Aktiv: Die Frau kaufte das Haus.
Passiv: Das Haus wurde von der Frau gekauft.
Aktiv: Das Fernsehen informierte den Zuschauer.
Passiv: Der Zuschauer wurde durch das Fernsehen informiert.

Perfekt / Plusquamperfekt

الماضي المركب / التام

Formel

sein (Präsens / Präteritum) + Partizip II + worden

Aktiv: Die Eltern haben das Kind geküsst.
Passiv: Das Kind ist von den Eltern geküsst worden.
Aktiv: Die Eltern hatten das Kind geküsst.
Passiv: Das Kind war von den Eltern geküsst worden.

لاحظ: نقول worden وليس geworden، والفعل المساعد هو sein وليس haben.

Futur I

المستقبل

Formel

werden (Präsens) + Partizip II + werden (Infinitiv)

Aktiv: Die Eltern werden das Kind küssen.
Passiv: Das Kind wird von den Eltern geküsst werden.

Futur I في المبني للمجهول نادر في الكلام اليومي، ويظهر في الامتحانات.

حالات خاصة

ohne Agens: Das Haus wird gekauft.
man → Ø: Man baut das Haus. → Das Haus wird gebaut.
Dativ bleibt: Man hilft dem Kind. → Dem Kind wird geholfen.
Vorgang / Zustand: Das Haus wird verkauft. | Das Haus ist verkauft.

آخر سطر: werden + Partizip II يصف <b>عملية</b> (Vorgangspassiv)، وsein + Partizip II يصف <b>حالة</b> (Zustandspassiv).

Passiv mit Modalverben

Präsens

المضارع

Formel

Modalverb (Präsens) + Partizip II + werden

Aktiv: Der Mensch soll die Natur respektieren.
Passiv: Die Natur soll vom Menschen respektiert werden.

Präteritum

الماضي البسيط

Formel

Modalverb (Präteritum) + Partizip II + werden

Aktiv: Der Mensch sollte die Natur respektieren.
Passiv: Die Natur sollte vom Menschen respektiert werden.

Perfekt / Plusquamperfekt

الماضي المركب / التام

Formel

haben (Präsens / Präteritum) + Partizip II + werden + Modalverb (Infinitiv)

Aktiv: Der Mensch hat (hatte) die Natur respektieren sollen.
Passiv: Die Natur hat (hatte) vom Menschen respektiert werden sollen.

هذا هو Doppelter Infinitiv: مصدران في آخر الجملة، ولا نستعمل Partizip II للمودال. <a href="../#doppelt">راجع القاعدة ‹</a>

Futur I

المستقبل

Formel

werden (Präsens) + Partizip II + werden + Modalverb (Infinitiv)

Aktiv: Die Schülerin wird den Lehrer fragen müssen.
Passiv: Der Lehrer wird von der Schülerin gefragt werden müssen.

🧭 كيف أحوّل الجملة إلى Passiv؟
  1. حدّد الزمن (Präsens، Präteritum، Perfekt، Futur I) وهل يوجد مودال.
  2. مفعول Akkusativ يصبح الفاعل الجديد.
  3. الفاعل القديم يصبح von + Dativ أو durch + Akkusativ (أو يُحذف مع man).
  4. صرّف werden في الزمن نفسه، وضع Partizip II في الآخر.
